# What's new

New features appear here when they ship. Choose **Update** under **Files** when the Tutorial has updates, and this page gains a section.

## October 2026

- **Read a whole cell.** Choose a cell in a spreadsheet or CSV, and the bar above the grid shows its whole text, however narrow the column. The arrow keys move from cell to cell. See [[Reading documents#Word and Excel]].

- **Sheets and Word documents as they were written.** Sheets show numbers in their own formats, error values and merged blocks, and a workbook with a chart sheet opens. Word tables keep merged cells, footnotes come through, and a document with tracked changes says so at the top. What cannot be converted, such as a text box, is marked where it stood. See [[Reading documents#Word and Excel]].

- **New conversations keep your model.** The model and reasoning effort you last chose start every new conversation. See [[The reading assistant#Models]].

- **Go to the cited page.** Ask the assistant to take you to a PDF page it cited, and the PDF opens at that page.

- **Thinking, counted.** While a model reasons before it answers, the line under the conversation reads *Thinking…* with the seconds so far. See [[The reading assistant#While it answers]].

- **Several conversations at once.** Switching conversations no longer stops an answer: the one you leave keeps answering. Choose the conversation's name at the top of the panel for a list of recent conversations, which marks those still answering and those with a reply you have not seen. See [[The reading assistant#Conversations]].

- **Conversation numbers.** Each conversation shows a number beside its name, such as `#k3X9qA`; choose it to copy it. Type `#` in the message box to pick another conversation, or paste a number, and the assistant reads that conversation. See [[The reading assistant#Conversations]].

- **Drag tabs into order.** Drag a tab along the tab bar to put it where you want it. The order is kept like the rest of your tabs. See [[Reading documents#Tabs]].

- **Recent files and stars.** Use **Recent** beside **Files** to reopen your last 50 files, or star a file with the button beside its name and find it under **Starred**. Each list has a filter, and each project remembers its own history, stars and selected view in this browser.

- **The assistant remembers.** Turn on memory under **Memory** in the project menu, and the assistant keeps what you ask it to remember, about you in every project and about a project in that project. The **Memory** tab lists, searches and corrects every note. See [[The reading assistant#Memory]].

- **Numbered cells, and the current cell.** Lab cells show `#1`, `#2` and so on, and the cell you were in is marked. Ask the assistant to *run cell 3* or to *explain the current cell*. See [[Labs#Run a cell]].

- **Add a cell, run it from the keyboard.** In a Lab, **Add cell** (**+**) adds an empty cell in the language you pick. ⌘Enter or Ctrl+Enter runs a cell, and **Shift+Enter** runs it and moves on to the next, adding one after the last. See [[Labs#Run a cell]].

- **This tutorial.** Every reader has a Tutorial project that follows the copy shipped with Gamma Reader. See [[Start here]].
- **Updates follow the source.** When a project's source changes a file, an update brings the new version in, replacing an edit you made to it, and says so first. See [[Files and projects#Keeping a project in step with a source]].
- **Sketches and pages inside notes.** Embed a p5 sketch or an HTML page with `![[name]]`, give it a size, and drag its corner to resize it. See [[Interactive pages]].
- **Links between notes.** Link with `[[name]]` to a note, a section, a named passage or a PDF page; see what links back; embed one note in another. See [[Links and embeds]].
- **The assistant runs Labs.** It can run a Lab's cells and read their results. See [[Labs#With the assistant]].
- **Web search.** Turn on **Search the web** for a conversation, and the assistant can search, cite links and save pages. See [[The reading assistant#Search the web]].
- **Emmy in Clojure cells.** Computer algebra, typeset as formulas. See [[Labs#Formulas as output]].
