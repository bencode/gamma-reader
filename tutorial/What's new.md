# What's new

New features appear here when they ship. Choose **Update** under **Files** when the Tutorial has updates, and this page gains a section.

## October 2026

- **This tutorial.** Every reader has a Tutorial project that follows the copy shipped with Gamma Reader. See [[Start here]].
- **Updates follow the source.** When a project's source changes a file, an update brings the new version in, replacing an edit you made to it, and says so first. See [[Files and projects#Keeping a project in step with a source]].
- **Sketches and pages inside notes.** Embed a p5 sketch or an HTML page with `![[name]]`, give it a size, and drag its corner to resize it. See [[Interactive pages]].
- **Links between notes.** Link with `[[name]]` to a note, a section, a named passage or a PDF page; see what links back; embed one note in another. See [[Links and embeds]].
- **The assistant runs Labs.** It can run a Lab's cells and read their results. See [[Labs#With the assistant]].
- **Web search.** Turn on **Search the web** for a conversation, and the assistant can search, cite links and save pages. See [[The reading assistant#Search the web]].
- **Emmy in Clojure cells.** Computer algebra, typeset as formulas. See [[Labs#Formulas as output]].
