# Product

## Register

product

## Users

Gamma Reader is for ordinary readers who want help understanding local documents without an account
or a technical workspace, and without having to arrange a model key before they can begin. They may
start with one file and add more context as their questions develop. Readers who do hold their own
keys can configure them and run on their own allowance; that path is open, not hidden, but it is
never a step on the way in.

## Product Purpose

Gamma Reader is a local-first reading companion for documents kept on the user's device. It should
make importing, previewing, comparing, and discussing files feel immediate while keeping document
data in browser storage unless the user explicitly chooses another destination. Success means a new
reader can open the app, start with the included files, add their own material, and stay focused on
the document rather than configuration.

## Brand Personality

Calm, precise, approachable.

## Anti-references

Avoid chat-first layouts that crowd out the document, setup-heavy developer tools, card-filled SaaS
dashboards, and file managers that expose unnecessary system concepts. Included files and files
added by the user should share one clear interaction model.

## Design Principles

- Keep reading as the largest and quietest part of the workspace.
- Let readers add context gradually instead of requiring organization up front.
- Keep document data local by default and explain the few actions that affect persistence.
- Delay write access until the user explicitly saves something to their file system.
- Prefer familiar controls, compact layout, and reversible actions for ordinary users.
- Keep the first run free of configuration, while leaving configuration reachable for those who want
  it.

## Accessibility & Inclusion

Meet WCAG AA for contrast and interaction. Support keyboard navigation, visible focus, reduced
motion, screen-reader labels, and status messages that do not rely on color alone.
